## Featured project

### [Roopam Bag Mall](https://github.com/shub262005/custom-bag-retail)

**A full-stack retail management application with a 3D custom bag designer.**

Customers can explore bag designs, customize a 3D preview, and submit requests. Store staff manage catalog data, inventory, purchases, counter sales, and reports through role-specific workflows.

- **Access control:** Customer, cashier, inventory manager, and admin roles, with JWT authentication and backend authorization.
- **Business workflows:** Inventory transactions, supplier payments, point-of-sale operations, sales cancellation, and audit history.
- **Interactive 3D:** Bag previews and customization using Three.js and React Three Fiber.
- **Data and testing:** PostgreSQL, Flyway migrations, backend unit tests, and opt-in database regression tests.

**Stack:** Java · Spring Boot · Spring Security · React · TypeScript · PostgreSQL · Three.js
